Eitquetas HTML

Este ejemplo muestra cómo combinar algunas de las etiquetas más básicas de HTML5.

Recuerda que es importante entender la diferencia entre ellas.

Etiqueta ul+li

Si listamos personas nominadas a los Ocscars, dado que el orden no altera el significado, debemmos usar ul.

  • David Verdaguer
  • Jesús Castro
  • Israel Elejalde
  • Dani Rovira

Etiqueta ol+li

En caso de que estemos listando elementos donde el orden es importante, como por ejemplo la clasificación de un mundial de futbol, debemos de usar ol

  1. España
  2. Países Bajos
  3. Alemania
  4. Uruguay
